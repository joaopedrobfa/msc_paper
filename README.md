# Payroll Tax Relief and Labour Market Informality: Evidence from Brazil
MSc Extended Essay, LSE Department of Economics (EC423), May 2026.

## Overview
This paper estimates the effect of Brazil's 2011 payroll tax relief programme
(the *desoneração da folha*) on labour market informality at the sector level.
Using PNAD Contínua microdata and exploiting the staggered rollout of the
reform across sectors (2011–2014), I apply the imputation estimator of
Borusyak et al. (2024), benchmarked against three alternative
difference-in-differences estimators (Callaway–Sant'Anna, de
Chaisemartin–D'Haultfœuille, and TWFE). The paper finds a positive but
statistically insignificant average effect on informality, with heterogeneity
across treatment cohorts pointing in opposite directions.

## Data
Uses microdata from the Pesquisa Nacional por Amostra de Domicílios Contínua
(PNADc), accessed via the [`PNADcIBGE`](https://cran.r-project.org/package=PNADcIBGE)
R package. Raw microdata is not included in this repository; scripts assume
it has been downloaded separately following the package's documentation.

## Structure
- `Scripts/` — analysis pipeline, run in order:
  - `0.master.R` / `0.master.do` — setup and library/package loads
  - `1.worker_level_panel_construction.R` — builds the worker-level panel
  - `2.sector_level_panel.R` — aggregates to the sector-quarter panel
  - `3.*` — BJS (Borusyak et al.) imputation estimation, weighted and unweighted
  - `4.*` — benchmark estimators: Callaway–Sant'Anna, de Chaisemartin–D'Haultfœuille, TWFE
  - `5.plot_*.R` — produces figures from `Results/`
- `Results/` — saved estimation output (`.RDS`, `.dta`), generated by the scripts in `3.*`/`4.*`
- `Graphs/` — figures produced by the `5.*` scripts
- `LSE Extended Essay.pdf` — final write-up

## Reproducing
Open the project in RStudio (`0.master.R` uses `here::here()`, so no manual
path edits are needed) or run the `.do` files from the repository root in
Stata. Requires PNADc microdata to be downloaded first (see Data above).
